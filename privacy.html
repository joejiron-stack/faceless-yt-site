Privacy Policy — Faceless YT Autopilot

Effective: November 07, 2026

Who operates this tool

Faceless YT Autopilot is a private software tool operated by a single individual (the "owner") for the owner's own YouTube channel. It has no other users. Contact: joejiron@gmail.com.

YouTube API Services

This tool uses YouTube API Services. By using it, the owner agrees to be bound by the YouTube Terms of Service. The Google Privacy Policy applies to data handled by Google. Authorization can be revoked at any time at Google security settings.

What data is accessed

  • The owner's own channel: video metadata the owner uploads, and the owner's channel and video analytics (views, watch time, subscribers gained, and estimated revenue once the channel is monetized).
  • Public data: public statistics (view counts, titles, publish dates, durations) of public YouTube videos and channels, used to research topics.

The tool does not access, collect, or store data about any other YouTube user, including viewers or commenters, and does not access any other person's account.

How data is used and stored

Data is used only to publish the owner's videos and to produce a private performance report for the owner. It is stored locally on the owner's computer in a database file. OAuth tokens are stored locally and are never shared. Public statistics retrieved for research are refreshed or deleted within 30 days. No data is sold, shared with third parties, or used for advertising.

Cookies

This website and the tool set no cookies and use no tracking.

Deletion

The owner can delete all stored data at any time by deleting the local database file and revoking access at Google security settings. Questions: joejiron@gmail.com.

Changes

Changes to this policy are posted on this page with a new effective date.
