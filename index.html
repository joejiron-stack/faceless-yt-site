Faceless YT Autopilot

Faceless YT Autopilot is a private, single-owner software tool. It produces original illustrated explainer videos for one YouTube channel owned and operated by the same person who runs the tool, and it uses the YouTube Data API and YouTube Analytics API only to:

  • upload that owner's own videos to that owner's own channel, set their thumbnails, and post a comment on them;
  • read public statistics for public videos and channels to research which topics people watch;
  • read the owner's own channel analytics (views, watch time, subscribers, and estimated revenue once monetized) to produce a private daily performance report for the owner.

The tool has no other users, no sign-up, and no public interface. It does not access any other person's account or private data.
